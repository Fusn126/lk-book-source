# 修改轻之国度书源
轻之国度的网站的api改掉了，老的书源完全不能用了。登录存入cookie逻辑暂时不变，其他网站进入逻辑需要变一下。
## 搜索
新搜索接口：https://www.lightnovel.fun/api/pc-proxy/api/bff/apk-search-result-v1 POST

提交参数：
其中q是搜索参数，sort默认这个值就好。
```
{
  "q": "我的",
  "scope": "",
  "source": "",
  "primary_tag": "",
  "channel_code": "",
  "work_type": "",
  "preset": "",
  "source_type": "",
  "filters": {},
  "word_count_bucket": "",
  "status_bucket": "",
  "page": 0,
  "pageSize": 20,
  "sort": "relevance"
}

```
返回json:
